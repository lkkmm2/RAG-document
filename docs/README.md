## 三条使用建议

1. **先跑通再读文档**。`python -m docqa.cli` + `streamlit run` 跑一遍，
   有了"手感"再回头看设计，比先读 500 行文档有效。
2. **讲项目不要背稿**。每个设计点记一句"结论"，展开用自己的话说——
   面试官能听出背稿，也能听出你是真做过。
3. **数字要记牢**：272 页 / 874 块 / 118 父块 / 45 条评测 /
   recall@4 0.70→0.90 / MRR 0.54→0.76 / 关键词命中 0.675→0.725 / 精排 2.7s。
   记错数字比不知道更致命。
