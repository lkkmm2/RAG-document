## 三条使用建议

1. **先跑通再读文档**。`python -m docqa.cli` + `streamlit run` 跑一遍，
   有了"手感"再回头看设计，比先读 500 行文档有效。
2. **面试问答不要背全文**，背每题的"结论"那一句，展开部分用自己的话说。
   面试官能听出背稿。
3. **数字要记牢**：272 页 / 874 块 / 118 父块 / 45 条评测 /
   recall@4 0.62→0.80 / MRR 0.48→0.68 / 精排 2.7s。
   记错数字比不知道更致命。
